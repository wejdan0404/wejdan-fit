## التحديثات البرمجية الجديدة في Sprint 02

1. **`fit-next.js`**: ترحيل نسخ البيانات إلى الإصدار الثالث دون تغيير الأصل؛ التحقق من السجلات؛ إحصاء تغذية الأسابيع للأيام المسجلة فقط؛ اتجاه وزن وصفي؛ أداء مقاومة بحسب نفس التمرين؛ فحص أولي لمسببات الحساسية؛ حساب حصة وصفة؛ مراجعة فارق السعرات من الماكروز؛ تقييم وضع الراحة.
2. **حماية الاستعادة:** تصدير JSON بتاريخ وإصدار، ومعاينة أعداد السجلات؛ أخذ snapshot مؤقت قبل استيراد WEJDAN FIT أو دمج Masari؛ عدم الاستبدال عند فشل حفظ snapshot؛ زر استرجاع الحالة السابقة. لاحظي: snapshot داخل المتصفح وليس بديلاً عن نسخة خارجية.
3. **تسجيل واقعي:** مراجعة وتعديل عدات وأوزان ومجهود جلسة قديمة، مع الحفاظ على حالة إكمالها؛ ظهور آخر أداء ضمن صفحة التمرين؛ إمكانية تأجيل حركة كتبتي أنها ممنوعة؛ لا اقتراح بديل طبي آلي.
4. **تغذية:** تغيير حجم حصة وصفات مساري بنسب (0.5 / 1 / 1.5 / 2)، ونقل القيمة التقديرية إلى سجل الوجبتين بعد موافقة مراجعة الملصقات. قائمة مشتريات محلية واختصارات لضم مكونات الوصفة. تجنُّب الأسماء المعلومة للفول السوداني وجوز الهند؛ **فحص الكلمات ليس ضمان حساسية**.
5. **متابعة:** قياسات اختيارية للخصر والورك والصدر والذراع؛ متوسط وزن وصفي عند كفاية المدخلات؛ متوسط السعرات حسب أيام الإدخال فقط؛ حفظ انعكاس أسبوعي؛ سجل الأيام الهادئة والراحة ومكاسب غير مرتبطة بالوزن.
6. **الهوية وسهولة الاستخدام:** استخدام شعار Figma السابق، المحافظة على Light/Dark وRTL، تحسين الفوكس وتصميم قوائم الجوال، وإشعار تحديث PWA مع إرجاء التحديث حتى يختاره المستخدم. خيار لإخفاء الأرقام الرئيسية للسعرات من الملخصات.

## التحقق الفعلي

- `node --check` لجميع ملفات JS الأساسية، بما فيها `fit-next.js`.
- `node tests/regression.js`, `node tests/fit-core.test.js`, `node tests/fit-next.test.js`, `node tests/masari-merge.test.js`.
- `python tests/browser_smoke.py`: محاكاة Chromium على 390×844، مع اختبار الحفظ بعد إعادة إنشاء الصفحة، جلسة جزئية ثم مكتملة، تعديل جلسة قديمة، اليوم الهادئ، الحصة الغذائية، المشتريات، القياسات، مراجعة الأسبوع وقيود التمرين، وعدم التمرير الأفقي.
- **اختبار HTTP حقيقي لخدمة PWA محجوب في بيئة المتصفح هذه** (`ERR_BLOCKED_BY_ADMINISTRATOR`)؛ لا نعتبر عمل Service Worker دون إنترنت أو تثبيت Safari ناجحًا حتى يتم اختباره على جهاز حقيقي.

5. اعتماد صريح لدمج Draft PR → `main`. لا نشر تلقائي ولا جمع لملفات صحية أو سجل شخصي على GitHub العام.
