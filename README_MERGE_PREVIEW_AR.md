# تجربة دمج «مساري الصحي» داخل WEJDAN FIT

**هذه نسخة تطوير من الفرع `feature/masari-safe-merge-v1`، وليست نسخة الإنتاج.**

## الموجود الآن

- 85 وصفة من ملف مساري مع المقادير بالجرام وشرح التحضير، و4 وصفات محجوبة بسبب الفول السوداني.
- 46 تمرينًا في مكتبة مرجعية غير مفعّلة ضمن برنامج المقاومة الحالي A/B.
- أداة استيراد آمن لسجل «مساري الصحي» من ملف JSON مع معاينة وحفظ القديم ومنع التكرار.
- الحفاظ على هوية Figma وLight/Dark والمكتبة الحالية والفيديوهات الحالية.

## كيف أجرب محليًا؟

فكّي الملف المضغوط وافتحي مجلده في الطرفية، ثم `python3 -m http.server 8000` وافتحي `http://localhost:8000`. للتجربة على جوالك من نفس الشبكة تحتاجين خادمًا يمكن للجوال الوصول إليه، لكن **لا تنقلي النسخة إلى رابط الإنتاج قبل القبول**.

داخل التطبيق: «أكلي» → «وصفات مساري»، «تماريني» → «مكتبة مساري المرجعية»، «المزيد» → «نقل آمن من مساري». ملف JSON الاحتياطي يبقى على جهازك؛ لا ترفعيه علنًا.

[خطة الدمج والقبول](docs/MASARI_MERGE_PLAN_AR.md)

### اختبارات محلية

```bash
node tests/regression.js
node tests/masari-merge.test.js
```

**القيود:** قيم الغذاء تقديرية، تدقيق الحساسية غير مكتمل، فيديوهات مساري وصوره لم تُنشر، ولم تُختبر النسخة الجديدة على آيفون حقيقي. النسخة المنشورة على `main` لم تتغير.
